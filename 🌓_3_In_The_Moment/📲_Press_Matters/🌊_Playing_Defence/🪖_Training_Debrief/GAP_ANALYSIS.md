## 🕳️ Likely substantive gaps worth a deliberate second pass

### Party-policy comparison

The working notes contain a substantial comparative section on Conservatives, Labour, Liberal Democrats, Greens and Reform. This material does not obviously belong inside the clinical core unless the cluster intends to evaluate alternative governing programmes. It may be better routed to a separate comparative Defence-policy node rather than scattered through diagnosis and management.

### Operation Fortress / Channel tasking

The notes contain a developed force-tasking case study: Coastguard, Border Force, military opportunity cost, intervention-created responsibility and the **Tuesday-roster test**. The Tuesday-roster method belongs in this cluster; the full party-specific Operation Fortress material may be cleaner as a separate worked example linked from readiness/force-design nodes.

### JSP and administrative burden

The notes identify a real research question around accumulated compliance architecture versus genuine risk control. This remains a research queue item unless a node already contains a sourced treatment. It should not be promoted merely from the notes.

### Veteran-politician tokenisation

The notes contain a useful governance point that one veteran politician cannot stand in for the entire Armed Forces. This is conceptually distinct from the core £30m case and may belong in a political-governance node unless it becomes necessary to interpret ministerial legitimacy claims.

### Transparency node

This is the largest actual recovery gap. The intended Brown/Stirrup/FOI/Chilcot/earned-loyalty analysis is represented elsewhere in fragments and working notes, but the dedicated drafted file itself is absent from this upload. Recover the original draft if possible rather than recreating it from secondary traces.

### Assessment node

The supplied assessment draft is also truncated. The opening differential survives, but the actual differential testing does not. Recover the original before treating the node as publication-ready.

# 🧬_which_russia_is_speaking.md

- Purpose:
  - synthesis node;
  - test whether contemporary Russian state identity is operating as a hybrid historical system.

- Candidate repertoires:
  - Petrine;
  - Romanov / imperial;
  - Soviet;
  - late-Soviet;
  - post-Soviet;
  - Putin-era security state;
  - contemporary nationalist / civilisational.

- Working hypothesis:
  > Contemporary Russia may not be choosing between Empire and USSR. It may be treating selected elements of both, plus post-Soviet grievance and Putin-era state restoration, as one usable historical inheritance.

- Possible package:

  - Romanov:
    - prestige;
    - Orthodoxy;
    - empire;
    - great-power recognition;
    - European status.

  - Soviet:
    - victory;
    - endurance;
    - sacrifice;
    - industrial mobilisation;
    - intelligence-state competence;
    - superpower memory;
    - hostile-bloc framing.

  - Post-Soviet:
    - humiliation;
    - disorder;
    - economic collapse;
    - perceived Western exploitation;
    - loss of status.

  - Putin-era:
    - restored state capacity;
    - sovereignty;
    - multipolarity;
    - security-state continuity;
    - civilisational language;
    - restored international consequence.

- Central live question:
  - which register appears:
    - for domestic audiences?
    - for Washington?
    - for Britain?
    - for Germany?
    - for NATO?
    - for Ukraine?
    - for the wider world?

- Link directly to audience architecture later:
  - same state;
  - different historical vocabulary;
  - different audience;
  - different intended political effect.

- Falsification questions:
  - are we seeing actual recurring repertoires?
  - or are we just retrospectively fitting history around ordinary strategic behaviour?
  - does identifying the repertoire improve prediction?
  - does it explain audience differentiation better than simpler models?

- Strong working line:
  > The real question may not be “Which Russia has returned?” but “Which Russian past is being activated for this audience, in this dispute, for this purpose?”

- End-state of this subcluster:
  - Peter node = specific ruler / geopolitical grammar.
  - Romanov node = cultural storehouse.
  - analogy-break node = limits.
  - Soviet node = competing / overlapping inheritance.
  - synthesis node = test the hybrid-state hypothesis.

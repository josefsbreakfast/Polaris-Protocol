# 📈_predictions_and_falsification.md

- Purpose:
  - make the cluster prospectively testable;
  - prevent historical / cultural interpretation becoming an unfalsifiable story that always looks correct after the event.

- Core principle:
  > Write down what we think the signal means before we know what happens next.

- Mandatory fields:

  DATE:
  SIGNAL:
  OBSERVED:
  INFERENCE:
  ALTERNATIVE:
  PREDICTION:
  CONFIDENCE:
  RESULT:
  UPDATE:

- Hypothesis becomes stronger if:
  - historical / status language recurs prospectively;
  - different Western states repeatedly receive differentiated Russian treatment;
  - coercive rhetoric repeatedly coexists with preserved diplomatic / intelligence channels;
  - later diplomatic positions correspond with earlier signalling;
  - Russian domestic narratives repeatedly emphasise:
    - recognition;
    - great-power status;
    - negotiated equality;
  - historical / cultural interpretation predicts developments missed by capability-only analysis.

- Hypothesis becomes weaker if:
  - supposed historical patterns disappear;
  - audience differentiation does not recur;
  - preserved channels repeatedly prove strategically meaningless;
  - apparent diplomatic openings consistently lead nowhere;
  - Moscow rejects viable status-preserving settlements compatible with Ukrainian sovereignty;
  - battlefield / capability explanations predict events better;
  - historical explanation only becomes visible retrospectively.

- Romanov-specific falsification:
  - if Peter / imperial language does not recur meaningfully;
  - if Soviet / contemporary explanations fit better;
  - reduce the importance of the Romanov frame.

- Audience-architecture falsification:
  - if Washington, Britain, Germany, France, Poland, etc. are not treated systematically differently;
  - do not force audience hierarchy onto events.

- Data / infrastructure falsification:
  - if Russian targeting / signalling remains narrowly military;
  - do not assume private infrastructure has entered Moscow's practical threat model merely because Western governments classify it as strategic.

- Press hypothesis:
  - record whether specialist analysis later identifies dimensions absent from immediate press coverage.
  - if it does not:
    - update the claim that public reporting systematically underweights them.

- Important discipline:
  - never delete failed predictions.
  - never silently rewrite them.
  - date revisions.
  - preserve why the original interpretation looked plausible.

- Use confidence labels:
  - low;
  - medium;
  - high.

- Avoid:
  - "called it" culture;
  - selecting only successful predictions;
  - expanding the theory until every outcome fits.

- Success metric:
  - not:
    > Polaris was right.
  - but:
    > Did this interpretive framework produce better questions, clearer uncertainty, or more accurate prospective expectations?

- Strong working line:
  > A hypothesis that cannot lose is not a useful defence-analysis tool.

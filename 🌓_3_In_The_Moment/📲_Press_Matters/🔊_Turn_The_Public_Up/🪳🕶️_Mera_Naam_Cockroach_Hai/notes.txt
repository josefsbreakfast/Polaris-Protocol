# 🪳🕶️ Mera Naam Cockroach Hai — Possible Node Inventory

**Working purpose:** a deliberately over-inclusive inventory of every substantial node, subcluster or title variant proposed in the conversation, resorted beneath the current lean file structure.

This is **not** a commitment to create every file. It is a parking map for editing, merging, renaming, moving or deleting ideas together.

Naming follows the current convention:

- folders use capitalised words;
- terminal Markdown files use lower-case words;
- no numerical or alphabetical prefixes;
- title variants are preserved rather than silently discarded.

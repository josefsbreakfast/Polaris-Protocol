## 🛰️ Orientation

The simplest model is:

```text
giver → receiver
```

A more useful model is:

```text
source
→ collection
→ intermediary
→ processing
→ aggregation
→ allocation
→ downstream use
```

There may be many sources, intermediaries, products, and destinations.

The person at the end may never encounter the person at the beginning.

That is why provenance matters.

## 🧺 The Basket Is An Intermediary

Intermediation is not inherently exploitative. Editors, analysts, researchers, newsrooms, consultants, libraries, intelligence functions, and teams all transform information legitimately.

The question is:

> **What happened to the rights, restrictions, attribution, consent, context, and provenance attached to the material while it travelled?**

## 🏷️ Provenance Attenuation

```text
person
→ observation
→ datum
→ pattern
→ analyst summary
→ recommendation
→ briefing
→ decision
```

The final recipient may receive something useful without ever seeing the original source.

Where this occurs accidentally, it is a recordkeeping problem.

Where it occurs through ordinary aggregation, it is a governance problem.

Where it is deliberately used to conceal an improper source, it becomes an investigative problem.

## 🎁 What Does The Receiver Receive?

Often, not a feather.

They may receive a better decision, phrase, introduction, prediction, warning, creative direction, recommendation, or better-timed intervention.

The relevant counterfactual is:

> **What would have happened without this input?**

Sometimes: the same thing.

Sometimes: a marginal improvement.

Sometimes: a material change.

Value must be traced through the decision chain rather than inferred from resemblance.

## 📋 Information Can Be Reused

```text
one extraction
→ copied
→ recombined
→ reused
→ repurposed
→ supplied again
```

Stopping one use does not necessarily remove every copy.

This is why remedy may require more than telling the source to control future publication.

## 🚫 Defensive Practice Is Not Remedy

A source can sometimes preserve originals, timestamps, version histories, authorship statements, licences, and a chronology.

Those practices can improve evidence.

They do **not** solve opaque downstream extraction.

A person cannot personally enforce provenance across systems they cannot see, inspect logs they cannot access, compel intermediaries they do not know exist, or account for value created inside organisations that do not disclose the supply chain.

So distinguish:

```text
source-side defensive practice
≠ institutional remedy
```

The actual governance questions include:
- Which custodian had a provenance duty?
- Which intermediary transformed the material?
- Was onward use logged?
- Can derived products be traced?
- Can the source correct or challenge provenance?
- Who can compel evidence where public access ends?
- What happens to copies already distributed?
- How is downstream value accounted for?
- What restitution is possible?

## 🔄 Follow The Map Backwards — Institutionally

Network mapping can become accountability mapping.

Identity resolution can become provenance resolution.

Longitudinal records can become authorship evidence.

Aggregation can support collective standards.

But the purpose is not to make every source their own forensic department.

The same technical capacities used to route value can be designed to preserve:
- source identity where appropriate,
- lawful-basis metadata,
- permissions,
- transformation history,
- onward disclosure,
- attribution,
- compensation status,
- and auditability.

> **If the system can remember which feathers are useful, it can also be designed to remember where they came from.**

## ⚖️ Restitution Is A Supply-Chain Question

Where improper extraction is established, remedy may involve:
- stopping future use,
- correcting provenance,
- restoring attribution,
- deleting or quarantining copies where lawful and feasible,
- compensating value already taken,
- correcting downstream records,
- notifying affected recipients,
- reviewing decisions materially influenced by the input,
- and accounting for opportunities lost by the source.

Not every remedy will be possible in every context.

But “set better boundaries next time” is not an adequate response to value already extracted.

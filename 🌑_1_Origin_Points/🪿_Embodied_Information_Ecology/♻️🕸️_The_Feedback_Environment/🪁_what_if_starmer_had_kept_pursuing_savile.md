# 🪁 What If Starmer Had Kept Pursuing Savile?

**First created:** 2026-09-30 \| **Last updated:** 2026-09-30\
*What might Britain have learned if the information-system diagnosis
exposed by the Savile prosecution failure had been pursued as a
sustained institutional research programme?*

------------------------------------------------------------------------

## 🛰️ Orientation

There is an important correction to make before this node goes anywhere.

Keir Starmer did **not** personally make the 2009 decision not to
prosecute Jimmy Savile.

Starmer was Director of Public Prosecutions when the failure became
publicly visible after Savile's death. He commissioned Alison Levitt QC
to review the CPS handling of the earlier allegations, published her
report, apologised for the CPS failures it identified, and used the
episode to drive changes in the handling of sexual-abuse cases.

So this node does not ask:

> **What if Starmer had prosecuted Savile?**

That is the wrong counterfactual.

It asks:

> **What if the systems diagnosis exposed by the Savile failure --- and
> taken seriously by Starmer while DPP --- had become a sustained,
> properly resourced research and audit programme across British
> institutions?**

The Mann sibling node asks:

> **How does an institution forget information it previously received?**

This node asks something slightly different:

> **How does an institution fail to know what it already knows?**

Because the Savile problem was not simply an absence of information.

People spoke.

Information entered institutions.

Police possessed allegations.

The CPS considered evidence.

Hospitals, broadcasters, schools, charities and other organisations had
their own fragments of information across Savile's extraordinarily long
period of offending.

Yet the fragments did not reliably become a pattern.

That is not merely a prosecution problem.

It is an **information ecology problem**.

------------------------------------------------------------------------

## 🧭 1. Start With What Actually Happened

Savile died in October 2011.

In 2012, allegations of extensive sexual abuse became public and the
scale of institutional contact around him began to emerge.

The CPS had previously considered allegations relating to Savile in 2009
and no prosecution followed.

As DPP, Starmer commissioned Alison Levitt QC to examine how the CPS had
handled those cases.

Levitt's review was published in January 2013.

Its conclusions were uncomfortable.

There was no finding that prosecutors or police had acted with an
improper motive to protect Savile.

But the process had failed.

Levitt concluded that prosecution might have been possible in relation
to three complainants if police and prosecutors had taken a different
approach.

A central problem was the way the complainants had been treated as
isolated evidential units.

The information existed.

The system failed to make enough information **relational**.

That distinction is the heart of this node.

------------------------------------------------------------------------

## 🧩 2. Four Pieces Of Information Are Not Necessarily Four Cases

Imagine four independent complainants.

``` text
A ──→ police
B ──→ police
C ──→ police
D ──→ police
```

If each is processed independently:

``` text
A → is A strong enough alone?
B → is B strong enough alone?
C → is C strong enough alone?
D → is D strong enough alone?
```

the institution may produce:

``` text
A → no prosecution
B → no prosecution
C → no prosecution
D → no prosecution
```

But there is another information object:

``` text
A + B + C + D
```

That object does not exist naturally.

The institution has to **make it visible**.

It must notice:

-   the same alleged perpetrator;
-   similar behaviour;
-   similar locations;
-   similar access mechanisms;
-   temporal patterns;
-   independent descriptions;
-   opportunity structures;
-   institutional affiliations;
-   and mutually corroborative features.

The relevant question therefore changes.

Not merely:

> **Is A sufficient?**

But:

> **What does A mean in the presence of B, C and D?**

Information has no fixed meaning independent of the system processing
it.

The same allegation can carry radically different informational value
once another independent allegation exists.

------------------------------------------------------------------------

## 🕸️ 3. The Network Failed To Network

This is perhaps the cleanest cybernetic description of Savile.

Britain had many institutions.

Savile moved through many institutions.

Information about him appeared in many institutions.

But the information environment did not reliably construct:

``` text
        SAVILE
       /  |  \
      /   |   \
 police  NHS  BBC
   |      |     |
 local   staff  colleagues
 info    info   info
      \   |   /
       \  |  /
       PATTERN
```

Instead, the ecology frequently looked more like:

``` text
institution A → fragment

institution B → fragment

institution C → fragment

institution D → fragment
```

with no sufficiently powerful mechanism producing:

``` text
fragment + fragment + fragment + fragment
                     ↓
                 pattern
```

This is not unique to Savile.

It is a general problem of distributed knowledge.

An organisation can contain every piece required to recognise danger and
still fail to possess the danger as an **organisational fact**.

------------------------------------------------------------------------

## 🚧 4. Thresholds Can Become Information Dead-Ends

A criminal prosecution requires an evidential threshold.

That is necessary.

But an information environment becomes dangerous when:

``` text
does not meet prosecution threshold
                ↓
        INFORMATION ENDS
```

because information can be insufficient for one institutional output
while remaining highly relevant to another.

For example:

``` text
insufficient for charge
        ↓
still relevant to:
        ↓
safeguarding
intelligence
employment risk
future allegations
pattern detection
licensing
professional regulation
institutional access
```

This is where the Savile episode becomes bigger than the CPS.

The important question is not whether criminal evidential standards
should be lowered.

They should not be confused with safeguarding thresholds.

The question is:

> **What happens to information after it fails to produce Output A?**

Does it disappear?

Or is it safely and lawfully routed toward every other system for which
it remains relevant?

A threshold should determine an action.

It should not automatically determine whether information continues to
exist.

------------------------------------------------------------------------

## 🪁 5. Starmer's Interesting Move Was To Generalise

Starmer did not respond to the Levitt report merely by saying:

> *That prosecutor got it wrong.*

The response treated Savile as exposing broader failures in how
sexual-abuse allegations were assessed.

The CPS subsequently developed changes including specialist approaches
to child sexual abuse, revised police/prosecutor guidance, greater
attention to the overall credibility of allegations rather than
stereotypes about complainants, and stronger emphasis on testing
suspects' accounts rather than placing the analytical burden almost
entirely on victims.

That matters.

It is a shift from:

``` text
WHY MIGHT THIS VICTIM BE WRONG?
```

towards:

``` text
WHAT EXPLANATION BEST FITS THE AVAILABLE INFORMATION?
```

Those are not equivalent questions.

The first can turn vulnerability, delay, trauma, inconsistency or social
marginalisation into reasons to discard information.

The second asks the investigator to test the entire system of competing
explanations.

That is an epistemic reform.

------------------------------------------------------------------------

## 🧠 6. Credibility Is Produced Contextually

Sexual abuse creates particularly difficult information.

A disclosure may be:

-   delayed;
-   partial;
-   inconsistent in peripheral detail;
-   made after previous silence;
-   accompanied by continuing contact with the alleged perpetrator;
-   made by someone vulnerable;
-   made by somebody with mental-health difficulties;
-   made by somebody who previously withdrew;
-   or made without documentary corroboration.

Historically, systems could treat those features as properties of the
allegation:

``` text
delayed
=
less credible
```

But Embodied Information Ecology asks:

> **Delayed relative to what environment?**

If the alleged perpetrator is:

-   famous;
-   institutionally powerful;
-   socially trusted;
-   surrounded by deferential adults;
-   capable of controlling access;
-   associated with respected institutions;
-   or able to move between organisations,

then delay may be information about the **environment around
disclosure**, not merely information about the complainant.

Likewise:

> **Why did nobody speak?**

can be a badly framed question.

People may have spoken.

The better question can be:

> **What did the receiving systems do with speech?**

------------------------------------------------------------------------

## 🔍 7. Suspect-Centred Investigation Changes The Information Environment

One of the important post-Savile shifts was toward greater scrutiny of
the suspect's account and circumstances.

That matters because an investigation can otherwise become structurally
asymmetric.

``` text
complainant
 ↓
prove reliability
 ↓
explain delay
 ↓
explain inconsistency
 ↓
survive credibility testing
```

while:

``` text
suspect
 ↓
deny
```

A better system asks:

-   Does the suspect's account fit known movements?
-   Did the suspect have access?
-   Are there independent allegations?
-   Do those people know one another?
-   Are there recurring locations?
-   Is the alleged behaviour patterned?
-   Are institutional records consistent with opportunity?
-   Did colleagues record concerns?
-   Did access arrangements create vulnerability?
-   Does the denial explain the whole evidence set?

The information burden becomes more symmetrical.

That does not presume guilt.

It produces a better test.

------------------------------------------------------------------------

## 🧬 8. Savile Was An Access-System Problem

Savile's offending cannot be understood only as a sequence of encounters
between one offender and individual victims.

He possessed **access**.

Access was repeatedly produced by institutions.

Celebrity generated access.

Charitable status generated access.

Broadcasting generated access.

Hospitals generated access.

Social trust generated access.

Institutional familiarity generated access.

And repeated access generated opportunity.

So another information object should have existed:

``` text
PERSON
  ↓
unusually extensive unsupervised access
  ↓
multiple vulnerable populations
  ↓
multiple institutions
  ↓
recurring informal privilege
```

That pattern can matter even before a criminal allegation is proven.

The question becomes:

> **Who is being granted exceptional access, by whom, under what rules,
> with what oversight, and is information about concerns travelling with
> them between institutions?**

------------------------------------------------------------------------

## 🧱 9. Institutional Boundaries Protected The Pattern

A distributed offender can exploit --- deliberately or otherwise --- the
fact that organisations perceive locally.

The BBC knows BBC-Savile.

A hospital knows hospital-Savile.

Police know police-Savile.

A charity knows charity-Savile.

A school knows school-Savile.

But:

``` text
BBC-Savile
+
hospital-Savile
+
police-Savile
+
charity-Savile
```

may reveal something that none of those objects reveals independently.

This creates a fundamental safeguarding problem:

> **Who owns the cross-institutional pattern?**

If the answer is:

> *Nobody unless a criminal case reaches a particular threshold,*

then the system has constructed a blind spot.

------------------------------------------------------------------------

## 🧯 10. But Networking Information Has Risks Too

The answer cannot simply be:

> **SHARE EVERYTHING WITH EVERYONE.**

That produces different harms.

Information systems can:

-   spread false allegations;
-   destroy privacy;
-   create unchallengeable suspicion;
-   amplify malicious reports;
-   disproportionately target marginalised people;
-   contaminate witnesses;
-   undermine fair trials;
-   confuse intelligence with evidence;
-   and turn safeguarding databases into permanent reputational
    punishment.

So the design problem is not maximum sharing.

It is **governed relationality**.

We need to know:

-   what can be linked;
-   by whom;
-   for what purpose;
-   under what legal authority;
-   at what evidential status;
-   with what retention period;
-   with what audit trail;
-   with what correction mechanism;
-   and with what protection against intelligence silently becoming
    treated as proven fact.

The same architecture capable of finding a Savile pattern can become
dangerous if it cannot distinguish:

``` text
allegation
intelligence
corroboration
evidence
finding
conviction
```

The metadata matters.

------------------------------------------------------------------------

## ♻️ 11. A Disclosure Must Produce Feedback

A functioning system should not merely ingest disclosures.

It should produce traceable state changes.

``` text
disclosure
    ↓
recorded
    ↓
risk assessed
    ↓
linked where lawful
    ↓
referred where appropriate
    ↓
decision
    ↓
reason recorded
    ↓
information retained appropriately
    ↓
future relevant information arrives
    ↓
previous decision becomes reviewable
```

That last edge matters enormously.

A decision can be reasonable at **T1** and wrong at **T2** because the
information environment has changed.

``` text
T1:
A alone → insufficient

T2:
A + B + C → materially different evidential environment
```

Therefore:

> **"No further action" cannot always mean "never look at this again."**

A feedback-capable system needs a mechanism for old information to
regain significance when new information arrives.

------------------------------------------------------------------------

## 🔔 12. New Information Should Be Able To Wake Old Information Up

This is probably the central technical proposition of the node.

Imagine:

``` text
2009
Allegation A
 ↓
NFA
 ↓
retained with status metadata
```

Then:

``` text
2011
Allegation B
 ↓
same suspect / pattern match
 ↓
A wakes up
```

Then:

``` text
2012
Allegation C
 ↓
A + B + C reviewed together
```

The old information has not changed.

Its **meaning has**.

That is feedback.

A static database stores information.

A feedback environment can recognise when new information changes the
significance of old information.

------------------------------------------------------------------------

## 🧮 13. The Question Is Not "Did We Have A Database?"

A country can digitise every record and still fail.

The relevant questions are:

-   Are identities matched accurately?
-   Are aliases recognised?
-   Are organisations linked?
-   Can geographically separated reports be associated?
-   Can safeguarding and criminal systems communicate lawfully?
-   Does an NFA decision remain discoverable?
-   Can new information trigger review?
-   Are weak signals visible without being promoted into facts?
-   Can analysts see patterns without exposing unnecessary personal
    information?
-   Are humans responsible for reviewing machine-generated links?
-   Can a mistaken link be corrected?
-   Is every access and decision auditable?

The database is not the system.

The **rules governing movement, interpretation and feedback** are the
system.

## 🕰️ 14. What If Starmer Had Kept Pulling This Thread?

Again, he did not simply abandon sexual-abuse policy when the Savile
review ended.

The counterfactual is institutional.

Imagine that the Savile diagnosis became a ten-year research programme
asking:

> **Where does independently generated safeguarding information fail to
> become relational?**

Researchers could have followed cases across:

-   police forces;
-   CPS areas;
-   hospitals;
-   schools;
-   children's homes;
-   universities;
-   broadcasters;
-   religious institutions;
-   sports organisations;
-   charities;
-   local authorities;
-   professional regulators;
-   and employers.

For every serious case:

``` text
Who knew what?
When?
In which institution?
In what evidential form?
Who else knew something?
Could those fragments lawfully have been connected?
Were they?
If not, why not?
What changed when later information arrived?
```

Then compare cases.

Now the object of investigation is not one monster.

It is the **architecture that determines whether monsters become
visible**.

------------------------------------------------------------------------

## 🧪 15. Build A Savile Test

A useful modern safeguarding system should be able to pass a
deliberately uncomfortable test:

> **If a Savile-shaped information pattern entered Britain today, when
> would the system see it?**

Not:

> *Would we recognise Jimmy Savile?*

We know the answer because we know his name.

Construct a synthetic pattern instead.

``` text
Person X

Report A → police force 1 → NFA

Report B → NHS trust → safeguarding concern

Report C → employer → informal complaint

Report D → police force 2 → intelligence only

Report E → charity → access restriction

Report F → local authority → safeguarding referral
```

Remove the famous name.

Remove hindsight.

Then test:

-   Which systems link?
-   Which cannot legally link?
-   Which do not technically link?
-   Which retain information?
-   Which delete it?
-   Which generate an alert?
-   Who receives that alert?
-   What evidential status does it carry?
-   Who decides whether the pattern warrants human review?
-   Can the system explain afterwards why it did or did not act?

That is a proper feedback test.

------------------------------------------------------------------------

## 🧹 16. Better Networking Could Also Protect The Innocent

There is another reason to do this properly.

Fragmented information does not only conceal genuine patterns.

It can also make false patterns look stronger than they are.

A relational investigation might discover:

-   complainants were not independent;
-   allegations originated from the same erroneous source;
-   dates are impossible;
-   the accused was elsewhere;
-   institutional records contradict access;
-   apparently separate accounts actually derive from prior publicity;
-   or a database has merged two people with similar names.

Therefore good relational analysis can produce:

``` text
MORE CONFIDENCE
```

or:

``` text
LESS CONFIDENCE
```

It should do both.

A system that only knows how to accumulate suspicion is not intelligent.

------------------------------------------------------------------------

## 🏛️ 17. What Britain Eventually Built

The post-Savile period produced substantial change.

The CPS changed approaches to sexual-offence prosecutions.

Police and prosecutors developed joint guidance.

Victim credibility was reconsidered.

Specialist expertise increased.

The Victims' Right to Review scheme was introduced during Starmer's
tenure.

Operation Yewtree and subsequent investigations exposed offending
extending far beyond Savile.

Multiple institutional investigations examined how Savile obtained
access and how organisations failed to respond.

IICSA subsequently examined broader institutional failures in child
protection.

And in 2026, Parliament legislated further changes arising from IICSA,
including a mandatory reporting framework and an offence concerned with
obstructing required reports, with implementation work continuing.

So again:

> **Britain did learn.**

The question is whether it learned the whole systems lesson.

------------------------------------------------------------------------

## 🗓️ 18. The 2026 Question

The relevant question now is not:

> **Could Jimmy Savile get away with exactly the same things in exactly
> the same way?**

History does not repeat laboratory conditions.

The question is:

> **Can independently generated information about the same dangerous
> person still remain separated long enough for the pattern to remain
> institutionally invisible?**

That can be tested.

And 2026 is a particularly useful moment to test it because Britain is
changing the statutory reporting environment following IICSA.

Mandatory reporting increases the quantity of information entering the
system.

But more input does not automatically produce better knowledge.

In fact:

``` text
MORE REPORTS
     +
POOR LINKAGE
     +
POOR TRIAGE
     =
MORE NOISE
```

So the implementation question is not merely:

> **Will people report?**

It is:

> **What happens to the report after they do?**

## 🏛️ 19. Questions MPs Can Ask In 2026

These questions do not presuppose that current systems are failing.

They ask government to demonstrate how the system behaves.

### Cross-force pattern detection

-   To ask the Secretary of State for the Home Department what
    arrangements enable police forces to identify independent sexual
    offence allegations concerning the same suspect recorded by
    different forces.

-   To ask the Secretary of State for the Home Department whether
    allegations resulting in no further action remain searchable for the
    purpose of identifying subsequently emerging patterns of alleged
    sexual offending; and what safeguards govern such searches.

-   To ask the Secretary of State for the Home Department what
    mechanisms trigger reconsideration of a previous no-further-action
    decision when a separate police force subsequently records a
    materially similar allegation concerning the same person.

-   To ask the Secretary of State for the Home Department what audit has
    been undertaken of cases in which two or more police forces
    separately held sexual-offence intelligence concerning the same
    person before those records were linked.

### CPS feedback

-   To ask the Attorney General what mechanisms enable the Crown
    Prosecution Service to reconsider an earlier charging decision where
    materially relevant independent allegations subsequently become
    available.

-   To ask the Attorney General whether the CPS records whether
    prosecutors considering a sexual-offence case have searched for or
    been notified of relevant allegations concerning the same suspect in
    other police force areas.

-   To ask the Attorney General what assessment has been made of the
    long-term effect of the reforms introduced following Alison Levitt
    QC's review of the handling of allegations concerning Jimmy Savile.

-   To ask the Attorney General whether the CPS has undertaken any
    retrospective audit of sexual-offence cases resulting in no charge
    before the post-Savile reforms to identify cases in which
    subsequently available information materially altered the evidential
    picture.

### NFA is not deletion

-   To ask the Secretary of State for the Home Department what
    distinction police information systems maintain between an
    allegation found to be false, an allegation not substantiated, an
    investigation closed for insufficient evidence and an allegation
    resulting in no further action for another reason.

-   To ask the Secretary of State for the Home Department what
    safeguards prevent a no-further-action decision from being
    interpreted in later safeguarding or investigative processes as a
    finding that the original allegation was false.

-   To ask the Secretary of State for the Home Department what retention
    and review rules apply to information concerning serious sexual
    allegations that did not result in charge.

### Mandatory reporting

-   To ask the Secretary of State for the Home Department whether
    reports made under the mandatory reporting duty will receive unique
    identifiers capable of supporting audit across organisational
    boundaries.

-   To ask the Secretary of State for the Home Department how reports
    concerning the same alleged perpetrator made by different
    institutions will be identified as potentially related.

-   To ask the Secretary of State for the Home Department whether
    implementation testing of the mandatory reporting system includes
    scenarios involving multiple individually inconclusive reports
    concerning the same person.

-   To ask the Secretary of State for the Home Department what mechanism
    will allow a previous safeguarding decision to be automatically or
    manually reconsidered when materially relevant new information is
    subsequently received.

-   To ask the Secretary of State for the Home Department what
    safeguards will ensure that linked allegations retain their
    individual evidential status and are not treated as established
    facts merely because multiple records exist.

### Cross-institutional safeguarding

-   To ask the Secretary of State for Education what arrangements allow
    safeguarding concerns about an individual working across multiple
    educational institutions to be identified as potentially related.

-   To ask the Secretary of State for Health and Social Care what
    arrangements permit NHS organisations to identify safeguarding
    concerns involving individuals who hold honorary, voluntary,
    visiting or otherwise non-standard access across more than one
    organisation.

-   To ask the Secretary of State for Culture, Media and Sport what
    safeguarding standards apply where broadcasters, charities, sporting
    bodies or cultural institutions provide prominent individuals with
    repeated access to children or vulnerable people.

-   To ask the Secretary of State for the Home Department which public
    authority, if any, has responsibility for identifying cross-sector
    patterns where relevant information is separately held by police,
    health bodies, employers, charities and local authorities.

### Exceptional access

-   To ask the Secretary of State for Health and Social Care whether NHS
    organisations are required to record and periodically review
    exceptional access privileges granted to volunteers, celebrities,
    patrons or other persons who are neither patients nor ordinary
    members of staff.

-   To ask the Secretary of State for Education what guidance exists
    concerning safeguarding risks created by informal or exceptional
    access arrangements for high-profile visitors, patrons and donors.

-   To ask the Secretary of State for Culture, Media and Sport what
    assessment has been made of safeguarding risks arising where
    celebrity, charitable status or institutional prestige results in
    access outside ordinary supervisory arrangements.

### Does new information wake old information?

-   To ask the Secretary of State for the Home Department what technical
    or procedural mechanisms permit newly recorded sexual-offence
    information to trigger review of previously closed investigations
    concerning the same person.

-   To ask the Secretary of State for the Home Department how many
    previously closed sexual-offence investigations have been reopened
    in each of the last five years following receipt of a separate
    subsequent allegation concerning the same suspect.

-   To ask the Attorney General how many CPS decisions not to charge in
    sexual-offence cases have been reconsidered following receipt of
    materially relevant evidence from a separate complainant.

The point is not to generate a parliamentary fishing expedition.

It is to make the architecture describe itself.

## 📰 20. Questions Journalists Can Ask In 2026

Journalists can test the system from the other direction.

Do not begin with famous suspects.

Begin with **information journeys**.

### Find the fragment

For a well-documented modern case involving multiple reports:

-   When did the first report enter any institution?
-   What evidential status did it receive?
-   Was it retained?
-   Who could search it?
-   Was it visible nationally?
-   Was it visible outside that organisation?
-   What happened when the second report arrived?
-   Did anyone know the first existed?
-   If so, when?
-   What caused the link to be made?

### Find the dead-end

Whenever an institution says:

> **No further action was taken**

ask:

-   Why?
-   Does that mean false, unsubstantiated, insufficient evidence,
    jurisdictional problem, victim withdrawal, public-interest decision
    or something else?
-   How is that distinction encoded?
-   Does the record remain available for pattern analysis?
-   What new information would trigger review?
-   Has that ever happened?
-   Who owns the review decision?

### Find the boundary

Look for people whose access crosses organisations:

``` text
hospital + charity
school + sports club
broadcaster + charity
university + professional body
religious organisation + school
```

Then ask:

-   Does safeguarding information travel with them?
-   Should it?
-   Under what legal basis?
-   Who sees the whole pattern?
-   Is there anyone whose job is to see the whole pattern?

### Find the exceptional privilege

Ask institutions:

-   Who has unsupervised or unusual access without being ordinary staff?
-   How is that authorised?
-   Is it time limited?
-   Who reviews it?
-   Are complaints linked to access records?
-   Does celebrity or donor status alter normal procedures?
-   Are informal arrangements documented?

Do not ask whether the institution has **another Savile**.

Ask whether it has **Savile-shaped permissions**.

### Find the wake-up mechanism

Take a historical NFA case where a later allegation emerged.

Ask:

-   Did the old case automatically surface?
-   Did a human remember it?
-   Did the complainant have to tell investigators?
-   Did a database match the suspect?
-   Was the previous complainant recontacted?
-   Was the old evidential decision reconsidered?
-   Is there a written trigger policy?

If the answer is:

> *Someone happened to remember,*

that is not a robust feedback mechanism.

### Find the measurement problem

Ask the Home Office, CPS and safeguarding bodies:

-   Do you count reports?
-   Do you count linked reports?
-   Do you count reopened cases?
-   Do you count cross-force matches?
-   Do you count cross-institution matches?
-   Do you measure time from first fragment to pattern recognition?
-   Do you measure how often a later allegation changes the assessment
    of an earlier one?

If nobody measures the feedback loop, nobody knows whether it works.

## 🧪 21. Run The Savile Test

There is a practical experiment available now.

Build a synthetic safeguarding exercise.

Do **not** use Savile's name.

Create Person X.

Seed information lawfully into a test environment:

``` text
Police Force A
→ allegation
→ insufficient evidence

NHS Trust B
→ safeguarding concern
→ informal access restricted

Charity C
→ complaint
→ volunteer relationship ended

Police Force D
→ separate allegation
→ intelligence retained

Institution E
→ concern about unsupervised access
```

Then observe.

At what point does the system produce:

> **These records may concern the same person and require human
> review.**

Measure:

``` text
time to linkage
number of fragments required
institutions visible
false matches
missed matches
human review time
decision quality
auditability
privacy exposure
```

Then alter the variables.

Change the spelling of the name.

Use a nickname.

Move the person geographically.

Make them a volunteer rather than an employee.

Make one allegation historical.

Make one complainant withdraw.

Make one institution close.

Make one record NFA.

Make the person famous.

Then run it again.

That would tell us considerably more about whether Britain learned from
Savile than another ministerial assurance that agencies work closely
together.

## 🛡️ 22. The Anti-Savile System Must Also Be An Anti-Witch-Hunt System

This deserves its own guardrail.

The system must be capable of saying:

> **There is a pattern worth investigating.**

It must also be capable of saying:

> **These records do not independently corroborate one another.**

Or:

> **This person has been incorrectly matched.**

Or:

> **The allegation was investigated and positively disproved.**

Or:

> **The evidence remains unresolved.**

Otherwise networked information simply creates networked injustice.

The design objective is not:

``` text
MORE SUSPICION
```

It is:

``` text
BETTER CALIBRATED KNOWLEDGE
```

That requires preserving the difference between:

``` text
reported
suspected
investigated
unsubstantiated
contradicted
corroborated
charged
proved
```

A relational database without epistemic status is a rumour engine.

## 🪞 23. Mann And Starmer Are Different Failure Modes

Put the sibling nodes beside one another.

### ☔️ Mann

``` text
information enters institution
        ↓
```

## 🧿 24. What This Node Does Not Claim

This node does not claim that Starmer personally made the decision not
to prosecute Jimmy Savile in 2009.

It does not claim that every later CPS reform was personally designed by
Starmer.

It does not claim that linking allegations makes them true.

It does not advocate indiscriminate information sharing.

It does not treat police intelligence as equivalent to evidence.

It does not assume that every institution holding a fragment could

> acquire new meaning when it becomes relational, while preserving
> evidential status, privacy, fairness and the presumption of
> innocence?**

## 🧬 25. The Larger Polaris Proposition

Savile demonstrates something extremely important about information.

Information does not simply **exist**.

Its meaning depends partly on what else the observer can see.

``` text
A
```

can mean one thing.

``` text
A + B + C + D
```

can mean something radically different.

Therefore an information environment does not merely determine whether
information survives.

It determines **which relationships between pieces of information can
become visible**.

That means institutional fragmentation is epistemic architecture.

So are:

-   database boundaries;
-   professional jurisdictions;
-   evidential thresholds;
-   privacy rules;
-   referral pathways;
-   retention schedules;
-   search permissions;
-   identifiers;
-   organisational hierarchies;
-   and decisions about when old information can be reconsidered.

The Savile lesson is not:

> **Believe every allegation.**

It is not:

> **Share everything.**

It is:

> **Build systems capable of recognising when new information changes
> the meaning of information already held.**

Because sometimes everybody has one piece.

And nobody has the picture.

# 🌸 How Many Times Must We Forget

**First created:** 2026-09-30 \| **Last updated:** 2026-09-30\
**Status:** 🚧 **UNDER CONSTRUCTION --- live research node**\
*What happens when safeguarding questions take longer to resolve than
ministers, governments, inquiries, journalistic beats and public
attention last?*

------------------------------------------------------------------------

## 🛰️ Orientation

This node begins with a problem rather than a conclusion.

Across modern British institutional history, serious questions about
child sexual abuse, institutional safeguarding, police conduct,
surveillance, accountability and state knowledge have sometimes taken
**years or decades** to resolve.

During those years:

-   ministers change jobs;
-   governments change;
-   parliamentary priorities change;
-   inquiries change chairs;
-   journalists change beats;
-   institutions reorganise;
-   records move;
-   scandals compete;
-   wars happen;
-   elections happen;
-   constitutional crises happen;
-   people retire;
-   people die;
-   and the public information environment moves on.

Some of those changes are ordinary.

Some are unavoidable.

Some are consequences of finite attention.

Some may reflect institutional friction or self-protection.

Historical states also possess real capabilities for surveillance,
infiltration and disruption.

But:

``` text
CAPABILITY EXISTED
        ≠
CAPABILITY WAS USED HERE
```

and:

``` text
PERSON CHANGED FOCUS
        ≠
PERSON WAS REDIRECTED
```

and:

``` text
QUESTION LOST MOMENTUM
        ≠
SOMEBODY DELIBERATELY BURIED IT
```

The research problem is therefore not:

> **Who secretly made everybody stop asking?**

It is:

> **How many times can a state rediscover the same safeguarding problem
> before repeated loss of attention becomes part of the safeguarding
> problem itself?**

Or, more simply:

# **How many times must we forget?**

## 🌸 1. Forget

Not:

``` text
FORGOTTEN
```

Past tense.

Completed.

Historical.

Closed.

But:

``` text
FORGET
```

A verb.

A process.

Something a system can do repeatedly.

Because institutional forgetting is not only:

``` text
DOCUMENT LOST
```

It can also be:

``` text
QUESTION LOST
```

``` text
CONTEXT LOST
```

``` text
INVESTIGATOR MOVED
```

``` text

```

``` text
PORTFOLIO MOVED
```

``` text

```

``` text

```

``` text

```

``` text

```

The information may technically still exist.

The **attention capable of acting on it** may not.

## 🧒 3. CSA Is Still A Live Safeguarding Issue

The Independent Inquiry into Child Sexual Abuse was established on a
statutory footing in 2015 after an earlier inquiry process begun in
2014.

It reported in October 2022 after seven years of investigation.

Its final recommendations included:

-   a single set of core CSA/CSE data;
-   Child Protection Authorities for England and Wales;
-   a cabinet-level Minister for Children;
-   a public awareness campaign;
-   and mandatory reporting of child sexual abuse in specified
    circumstances.

In 2026, Parliament enacted major measures connected to the
mandatory-reporting recommendation through the Crime and Policing Act.

That is progress.

It is also a useful temporal fact.

``` text
2014
political recognition / inquiry beginnings

2015
statutory inquiry

2022
final report

2026
major reporting legislation
```

Safeguarding reform can therefore span:

``` text
MULTIPLE GOVERNMENTS
MULTIPLE HOME SECRETARIES
MULTIPLE PARLIAMENTS
MULTIPLE NEWS CYCLES
```

The question can remain live long after the political moment that
generated it has gone.

## 🏛️ 4. IICSA Already Found The Reputation Problem

This is not merely theoretical.

The government's 2026 summary of the IICSA recommendations records that
the Inquiry heard evidence from victims and survivors who disclosed
abuse or provided information to responsible adults without the relevant
authorities subsequently being informed.

It notes cases in which perpetrators continued to have access to
children despite senior leaders knowing children were at risk.

And it identifies a recurring reason:

> institutional or individual reputation was sometimes prioritised over
> children's safety.

That matters enormously for this cluster.

Because it means we do **not** have to hypothesise that reputation and
safeguarding can conflict.

A major statutory inquiry already found that they had.

The open question is what institutional architecture prevents that
conflict recurring.

## 🧺 5. The Dignity Of Office

There is a recurring political instinct to protect:

``` text
THE DIGNITY OF THE OFFICE
```

The Presidency.

The Crown.

Parliament.

Government.

Police.

Church.

School.

Party.

Institution.

Profession.

But institutional dignity cannot sensibly mean:

``` text
NOTHING HUMILIATING
BECOMES VISIBLE
```

A more robust definition would be:

``` text
WE CAN DISCOVER
SOMETHING TERRIBLE
INSIDE OUR OWN HOUSE

        ↓

PRESERVE THE EVIDENCE

        ↓

PROTECT THE PEOPLE HARMED

        ↓

INVESTIGATE IT

        ↓

DISCLOSE WHAT ACCOUNTABILITY REQUIRES

        ↓

PROTECT WHAT LEGITIMATELY
MUST REMAIN PRIVATE

        ↓

CORRECT THE SYSTEM

        ↓

SURVIVE THE EMBARRASSMENT
```

That is dignity.

Not spotless laundry.

A functioning washing machine.

## 🫧 6. Air The Laundry --- Carefully

"Air the laundry" does **not** mean radical indiscriminate transparency.

Safeguarding requires privacy.

Victims and survivors have rights.

Children have rights.

Investigations require confidentiality.

Intelligence may require protection.

Courts can legitimately restrict information.

Personal data may need redaction.

Some evidence should never become public.

So:

``` text
ACCOUNTABILITY
≠
PUBLISH EVERYTHING
```

But equally:

``` text
PRIVACY
≠
INSTITUTIONAL AMNESIA
```

and:

``` text
CONFIDENTIALITY
≠
NO AUDIT TRAIL
```

and:

``` text
DIGNITY
≠
NO EMBARRASSMENT
```

The objective is not maximal publicity.

It is **sufficient visibility for accountability**.

## 👩🏻‍💼 7. Theresa May Is A Useful Attention Case --- Not Evidence Of Redirection

Theresa May announced an independent inquiry into child sexual abuse in
2014 while Home Secretary.

In February 2015 she announced that it would be placed on a statutory
footing under the Inquiries Act 2005 with powers to compel evidence.

That is an important fact.

Then her political role changed dramatically.

She became Prime Minister in July 2016.

Her premiership became heavily occupied by the consequences of the EU
referendum and the process of Brexit.

None of that establishes:

``` text
SOMEBODY MOVED THERESA MAY
AWAY FROM CSA
```

It demonstrates something more ordinary and potentially more important:

> **The political attention that creates an inquiry may not remain
> attached to that inquiry for its lifetime.**

The inquiry persists.

The originating minister does not remain its minister.

The political environment changes.

Institutional memory therefore has to survive **role transition**.

## ⏳ 10. The Attention Half-Life

Call this:

> **attention half-life**

A serious institutional problem enters the political system with some
quantity of attention.

Over time:

``` text
ATTENTION
████████████████

        ↓

████████████

        ↓

████████

        ↓

████

        ↓

██
```

Unless something renews it.

Renewal can come from:

-   survivors;
-   journalism;
-   litigation;
-   parliamentary questions;
-   new evidence;
-   anniversaries;
-   inquiries;
-   campaigns;
-   whistleblowers;
-   prosecutions;
-   documentaries;
-   new scandals;
-   or another institutional failure.

The question is:

> **Does safeguarding depend upon somebody periodically making the issue
> newsworthy again?**

If yes, the system has a memory problem.

## 🚨 11. The Undercover Policing Inquiry Is A Useful Parallel

The Undercover Policing Inquiry was established in 2015 to examine
undercover policing in England and Wales since 1968.

It was originally expected to conclude within three years.

More than ten years later, it remains ongoing.

By 2026 the Home Office recorded expenditure exceeding £138 million and
launched a consultation on the Inquiry's future structure, scope and
format.

The consultation explicitly identifies among those affected:

-   women deceived into relationships with undercover officers;
-   individuals and groups reported on;
-   family members of deceased children whose identities were used;
-   family justice campaigns;
-   and others affected by undercover policing.

The remaining work described by the Home Office includes:

-   the National Public Order Intelligence Unit;
-   other undercover policing beyond the principal historic units;
-   management and oversight;
-   legal and regulatory frameworks;
-   and current and future undercover-policing practice.

So in 2026:

``` text
THE STATE IS STILL INVESTIGATING
HISTORICAL UNDERCOVER POLICING

WHILE ALSO DECIDING
HOW MUCH OF THE REMAINING
INVESTIGATION SHOULD CONTINUE
IN ITS CURRENT FORM
```

That is not evidence that the Inquiry is being improperly curtailed.

The government states that it is seeking a more effective route to
accountability, learning and reform without further unnecessary delay.

But it creates a legitimate research question:

> **How does a state preserve accountability when an accountability
> mechanism itself lasts long enough to become the subject of
> institutional redesign?**

## 🕵🏻 12. Capability Is Relevant --- But Capability Is Not Attribution

Undercover policing matters to this node for another reason.

The Inquiry exists because covert policing capabilities were actually
used over decades.

Its subject matter includes surveillance and reporting on political
groups and individuals and the conduct of undercover officers, including
deceptive intimate relationships.

Therefore:

``` text
BRITISH STATE HISTORICALLY POSSESSED
CAPABILITY TO COVERTLY ENTER
POLITICAL / ACTIVIST INFORMATION ENVIRONMENTS
```

is not speculative.

But:

``` text
CAPABILITY
```

does not establish:

``` text
USE IN A PARTICULAR CASE
```

Still less:

``` text
USE TO REDIRECT A PARTICULAR
CSA INVESTIGATION
```

The existence of capability changes what questions are **possible to
investigate**.

It does not answer them.

## 🧪 13. Four Competing Explanations

When a person who was pursuing or adjacent to a safeguarding question
later moves elsewhere, preserve at least four hypotheses.

### H1 --- Ordinary political turnover

People change jobs.

Governments change.

Elections happen.

Careers develop.

People retire.

### H2 --- Structural attention capture

Large events consume finite institutional attention.

Examples can include:

``` text
constitutional crisis
war
terrorism
pandemic
economic crisis
party crisis
major election
```

No one needs to redirect anybody.

The new event simply becomes overwhelmingly expensive in attention.

### H3 --- Institutional friction / self-protection

The work becomes:

-   slow;
-   procedurally difficult;
-   poorly resourced;
-   fragmented;
-   reputationally uncomfortable;
-   legally complex;
-   or repeatedly rerouted.

This can reduce persistence without requiring central coordination.

### H4 --- Deliberate interference or redirection

An actor intentionally attempts to:

-   surveil;
-   pressure;
-   intimidate;
-   discredit;
-   distract;
-   recruit;
-   threaten;
-   manipulate;
-   promote;
-   remove;
-   or otherwise alter the environment of someone pursuing the question.

H4 is historically possible.

It requires **case-specific evidence**.

Do not infer it from H1, H2 or H3.

For each relevant person:

  -----------------------------------------------------------------------

  ----------------------------------- -----------------------------------
  Person                              Who?

  First relevant date                 When did involvement begin?

  Evidence                            PQ, speech, inquiry role, casework,

  Comparator                          Did similar transitions happen

  Confidence                          High / medium / low / unknown
  -----------------------------------------------------------------------

The crucial column is:

``` text
CSA ACTIVITY AFTER TRANSITION
```

Because:

> **Moved elsewhere**

must never silently become:

> **Stopped caring.**

## 🧷 16. A Question Needs Custody

Documents have custodians.

Money has accounting officers.

Cases have case numbers.

Ministerial portfolios have departments.

What does an unresolved safeguarding **question** have?

Often:

``` text
NOTHING QUITE SO CLEAN
```

That is dangerous.

Because responsibility can become:

``` text
EVERYBODY KNOWS
        +
NOBODY OWNS
```

So add:

> **question custody**

For every unresolved institutional safeguarding question:

-   Who owns it now?
-   What record preserves it?
-   What event triggers review?
-   Who inherits it when personnel change?
-   When is its status reported?
-   What constitutes resolution?
-   Who can challenge a declaration of resolution?
-   Can new evidence reopen it?
-   Is there an audit trail showing why it was closed?

A question without custody is easy to forget.

From the Savile line:

> **New information should be able to wake old information up.**

> **New information should be able to wake old questions up.**

Not:

``` text
NEW SCANDAL
      ↓
START AGAIN FROM ZERO
```

But:

``` text
NEW INFORMATION
      ↓
SEARCH OLD RECORDS
      ↓

      ↓
RESTORE CONTEXT
      ↓
IDENTIFY PREVIOUS DECISION
      ↓
ASK WHETHER IT STILL HOLDS
```

The survivor should not have to become the institution's external hard
drive.

## 🧠 18. The Human Memory Problem

Institutions often talk as though:

``` text
THE DEPARTMENT KNOWS
```

But departments do not have brains.

People know.

Records preserve.

Systems retrieve.

Procedures route.

Successors learn.

If:

``` text
PERSON LEAVES
```

and:

``` text
RECORD IS POOR
```

and:

``` text
SUCCESSOR IS NOT BRIEFED
```

then:

``` text
INSTITUTION "FORGETS"
```

without any document necessarily being destroyed.

This is the bridge between:

``` text
INSTITUTIONAL MEMORY
```

and:

``` text
ATTENTION MEMORY
```

## 📰 19. Journalism Has The Same Problem

A journalist pursues a question.

Then:

-   moves beat;
-   moves paper;
-   becomes editor;
-   loses access;
-   gets assigned elsewhere;
-   leaves journalism;
-   or the newsroom loses funding.

The documents remain.

The **relational model in the journalist's head** disappears.

Years later another journalist finds one piece.

The story is described as:

``` text
NEW
```

when the more accurate description may be:

``` text
REACTIVATED
```

This is why archives, timelines, provenance and machine-assisted
retrieval matter.

The public information environment also needs institutional memory.

## 🤖 20. Robit And The Long Question

This is where Robit earns its keep.

Not:

``` text
🤖:
I HAVE SOLVED BRITISH HISTORY
```

Absolutely not.

But:

``` text
🤖:
this parliamentary question from 2014
appears to concern the same unresolved
record-routing issue as this inquiry
finding from 2022
```

or:

``` text
🤖:
this person changed role in 2016
but continued raising the issue in 2018,
so "attention ended" is not supported
```

or:

``` text
🤖:
we have no evidence for what happened
to this question between 2015 and 2019
```

That last output is extremely valuable.

A machine-assisted archive can preserve:

``` text
WE DO NOT KNOW
```

as a first-class research object.

## 🏛️ 21. Government Must Be Able To Outlive Government

A safeguarding architecture cannot depend upon:

``` text
THE RIGHT HOME SECRETARY
```

or:

``` text
THE RIGHT MP
```

or:

``` text
THE RIGHT JOURNALIST
```

or:

``` text
ONE VERY ANGRY SURVIVOR
WHO REFUSES TO GO AWAY
```

because all of those are fragile.

A democratic institution should be capable of saying:

``` text
THE PERSON WHO STARTED THIS
IS GONE

THE QUESTION IS NOT
```

That is institutional maturity.

## 🌊 22. Political Crisis Is Not A Conspiracy

Brexit matters here because it demonstrates attention competition.

So do pandemics.

Wars.

Elections.

Financial crises.

Major security events.

A political system has finite:

-   ministerial attention;
-   parliamentary time;
-   civil-service capacity;
-   media bandwidth;
-   public attention;
-   investigative resources.

Therefore:

``` text
CRISIS BECOMES DOMINANT
```

can produce:

``` text
OTHER IMPORTANT WORK
BECOMES LESS VISIBLE
```

without anyone deciding:

``` text
BURY OTHER IMPORTANT WORK
```

That distinction is essential.

But the safeguarding consequence can be real regardless of intent.

## ⚙️ 23. Time Can Become A Containment Mechanism Without Anyone Designing It

This is perhaps the central proposition.

Suppose:

``` text
inquiry takes 10 years
```

During those ten years:

``` text
witness dies
official retires
minister changes
records migrate
journalist leaves
institution restructures
public forgets context
survivor exhausts resources
```

No one has to say:

``` text
DELAY THIS UNTIL EVERYBODY FORGETS
```

for delay to have information effects.

Therefore:

> **Time can function as containment without having been deliberately
> deployed as containment.**

That does not mean delay is innocent.

It means motive and effect must be analysed separately.

## 🧯 24. But Deliberate Delay Remains A Separate Hypothesis

Where evidence exists of:

-   intentional stalling;
-   obstruction;
-   destruction;
-   improper withholding;
-   pressure on investigators;
-   deliberate narrowing;
-   politically motivated reassignment;
-   surveillance;
-   intimidation;
-   interference with witnesses;
-   misleading statements;
-   or strategic exhaustion,

record it.

But record:

``` text
DOCUMENTED DELAY
```

separately from:

``` text
DELIBERATE DELAY
```

and:

``` text
DELIBERATE DELAY
```

separately from:

``` text
WHY IT WAS DELAYED
```

Every arrow needs evidence.

## 🕵🏻 25. Undercover Capability Creates A Question, Not An Answer

The Undercover Policing Inquiry gives us documented historical evidence
that the British state possessed and used covert capabilities inside
political and activist environments.

That matters.

It means certain forms of interference are not science fiction.

But the evidential discipline must become **stricter**, not looser, once
that fact is known.

Otherwise:

``` text
THE STATE COULD DO X
```

becomes:

``` text
THE STATE DID X
```

and then:

``` text
THE STATE DID X HERE
```

and then:

``` text
X EXPLAINS EVERYTHING
```

in four extremely exciting but evidentially catastrophic steps.

No.

Capability establishes:

``` text
POSSIBLE MECHANISM
```

Case evidence establishes:

``` text
OPERATION
```

Keep them apart.

------------------------------------------------------------------------

## 🌸 26. Forgetting Is A Safeguarding Outcome

We usually think of safeguarding outcomes as:

``` text
child protected
offender stopped
institution reformed
```

But institutional memory should itself be treated as part of
safeguarding.

Because if a system repeatedly forgets:

-   previous allegations;
-   previous institutional failures;
-   previous recommendations;
-   previous warning signs;
-   previous investigative gaps;
-   previous record-routing failures;
-   previous patterns of access;
-   previous reasons reforms were introduced,

then future children encounter a system with artificially shortened
memory.

That is not merely an archival defect.

It changes risk.

## 🧪 28. Evidence Status For This Node

Because this node is under construction, claims should be tagged
conceptually as:

### 🟢 Established

Supported directly by primary records, inquiry findings, legislation,
official chronology or other strong evidence.

### 🟡 Supported inference

Evidence supports the mechanism, but causal attribution remains
incomplete.

### 🟠 Open question

Worth investigating; not established.

### 🔴 Unsupported

Do not publish as fact.

For example:

``` text
🟢 Theresa May established the inquiry process
   and later became Prime Minister.

🟢 Brexit became a central responsibility
   of her premiership.

🟠 Did the change in political role materially
   alter her personal attention to particular
   unresolved CSA questions?

🔴 Theresa May was deliberately redirected
   away from CSA.
```

Unless evidence emerges for the last proposition, it stays red.

``` text
OR OTHER EVIDENCE
```

actually connects them.

Until then:

``` text
PARALLEL LINES
```

remain parallel.

## 🧷 32. Questions For Journalists

When an old safeguarding issue returns:

-   Who asked this before?
-   What answer were they given?
-   What records existed then?
-   What records exist now?
-   What changed?
-   Who inherited responsibility?
-   Was the earlier question ever formally closed?
-   On what evidence?
-   Did the relevant recommendation become policy?
-   Did policy become law?
-   Did law become practice?
-   Was practice audited?
-   Did the institution measure whether the reform worked?
-   Which original participants had left by then?
-   What knowledge disappeared with them?
-   What documentation replaced that human memory?
-   Were survivors required to resupply information already given?
-   Did a later inquiry rediscover an earlier finding?
-   Did another crisis interrupt implementation?
-   Is the current "new" revelation actually new?
-   Who currently owns the unresolved question?

And:

> **How many times has this institution learned this already?**

## 🧺 33. Questions For Institutions

Do not ask only:

> **What did you know?**

Ask:

> **How do you prevent yourselves from forgetting it?**

Specifically:

-   What unresolved-issue register exists?
-   Who owns each item?
-   What happens when the owner leaves?
-   What is the handover requirement?
-   Are relevant records linked across departments?
-   Can new evidence trigger historical search?
-   How are recommendations tracked across administrations?
-   Who audits implementation?
-   Who audits effectiveness?
-   Who preserves the reason a reform was introduced?
-   What prevents a later administration quietly recreating the original
    risk?
-   How can survivors challenge an institution that claims a matter is
    resolved?

Institutional memory needs engineering.

## 🔔 34. The Dignity Test

When an institution says that disclosure, investigation or
acknowledgement may damage confidence, ask:

``` text
CONFIDENCE IN WHAT?
```

Confidence that:

``` text
NOTHING BAD EVER HAPPENED
```

is fragile.

Confidence that:

``` text
WHEN SOMETHING BAD HAPPENS
THE INSTITUTION CAN FIND IT,
ADMIT IT,
CORRECT IT,
PROTECT PEOPLE,
AND REMEMBER WHY
```

is much more robust.

The first requires reputation management.

The second requires institutional integrity.

That is the dignity worth protecting.

## ♻️ 35. The Feedback Test

A functioning safeguarding system should look like:

``` text
HARM / WARNING
      ↓
REPORT
      ↓
RECORD
      ↓
ROUTING
      ↓
INVESTIGATION
      ↓
FINDING
      ↓
REFORM
      ↓
IMPLEMENTATION
      ↓
MEASUREMENT
      ↓
MEMORY
      ↓
NEW WARNING
      ↓
OLD KNOWLEDGE WAKES UP
```

If instead:

``` text
HARM
 ↓
SCANDAL
 ↓
INQUIRY
 ↓
REPORT
 ↓
TIME
 ↓
PEOPLE MOVE
 ↓
CONTEXT FADES
 ↓
HARM
 ↓
SCANDAL
 ↓
NEW INQUIRY
```

then:

> **forgetting is inside the feedback loop.**

That is the problem this node is trying to measure.

## 🌸 36. How Many Times Must We Forget?

Perhaps the wrong question has been:

> **Why didn't somebody remember?**

Because "somebody" is not an institutional memory architecture.

A better question is:

> **What mechanism was supposed to make forgetting difficult?**

Where was the unresolved question stored?

Who inherited it?

What woke it up?

What prevented it disappearing when the minister moved?

When the investigator retired?

When the journalist changed beat?

When the government changed?

When the crisis arrived?

When the inquiry took ten years?

When the survivor got tired?

When everybody who remembered why the reform existed had left?

The measure of a safeguarding system is not merely whether it can
respond once.

It is whether it can **retain the lesson**.

So:

``` text
HOW MANY REPORTS?

HOW MANY REVIEWS?

HOW MANY INQUIRIES?

HOW MANY RECOMMENDATIONS?

HOW MANY MINISTERS?

HOW MANY REDISCOVERIES?

HOW MANY TIMES
MUST WE
```

# **forget**

## 🧿 37. What This Node Does Not Claim

This node does not claim that politicians who changed role were
deliberately redirected from CSA.

It does not claim that Brexit was created or used to distract from
safeguarding.

It does not claim that undercover policing was used against people
pursuing the CSA questions discussed here.

It does not infer covert action from the existence of covert capability.

It does not claim that every long inquiry is deliberately delayed.

It does not claim that every institutional loss of attention is
improper.

It does not treat privacy or lawful secrecy as concealment.

It does not argue that every safeguarding record should be public.

It does not assume that people whose portfolios changed ceased caring or
ceased acting.

It does not treat temporal correlation as evidence of intervention.

It asks a narrower and presently answerable question:

> **How well does the British institutional system preserve unresolved
> safeguarding questions across changes in people, office, attention and
> time?**

The more serious hypotheses remain open until evidence closes them.
